# Security policy

Report vulnerabilities privately through GitHub Security Advisories for `f0909172434/rigorgraph` after the repository is public. Do not include credentials, private research data, or exploitable payloads in public issues.

RigorGraph is local-first and has no telemetry or hosted service. Its main security boundaries are path traversal, unsafe HTML embedding, untrusted JSON/YAML input, evidence-file hashing, and supply-chain dependencies.

# RigorGraph v0.1.0-beta.1

RigorGraph は公開ベータになりました。AI 支援リサーチをローカルで監査可能な主張—証拠グラフに変換し、証明、文献上の支持、数値証拠、ベンチマーク証拠、不確実性を明確に区別します。

このベータには Python CLI、4 つのインストール可能なエージェントスキル、Codex plugin metadata、GitHub Action、決定的監査、数学およびベンチマークのデモ、英語・繁体字中国語・簡体字中国語・日本語に対応した自己完結型オフラインレポートが含まれます。

RigorGraph はワークフローの完全性と追跡可能性を確認しますが、研究上の主張が絶対的に正しいかどうかを判定しません。最初の外部ユーザー 5 名を募集しています。5 分間のデモを実行し、機密情報を含まない公開フィードバックをベータフィードバック issue フォームから送信してください。

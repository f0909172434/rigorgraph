# RigorGraph v0.1.0-beta.1

RigorGraph 现已进入公开 Beta。它把 AI 辅助研究转化为本地、可审计的命题—证据图，并严格区分证明、文献支持、数值证据、基准测试证据和不确定性。

本次 Beta 包含 Python CLI、四个可安装的代理技能、Codex plugin metadata、GitHub Action、确定性审计、数学与基准测试 demo，以及完整支持英文、繁中、简中、日文的自包含离线报告。

RigorGraph 检查工作流程完整性与可追溯性，不会判断研究命题是否绝对正确。我们正在寻找前 5 位外部用户；请运行五分钟 demo，并通过 Beta 反馈 issue 表单提交不含敏感数据的公开反馈。

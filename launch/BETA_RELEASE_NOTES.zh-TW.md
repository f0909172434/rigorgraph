# RigorGraph v0.1.0-beta.1

RigorGraph 現已進入公開 Beta。它把 AI 輔助研究轉化為本機、可稽核的命題—證據圖，並嚴格區分證明、文獻支持、數值證據、基準測試證據與不確定性。

本次 Beta 包含 Python CLI、四個可安裝的代理技能、Codex plugin metadata、GitHub Action、確定性稽核、數學與基準測試 demo，以及完整支援英文、繁中、簡中、日文的自包含離線報告。

RigorGraph 檢查工作流程完整性與可追溯性，不會判定研究命題是否絕對正確。我們正在尋找前 5 位外部使用者；請執行五分鐘 demo，並透過 Beta 回饋 issue 表單提交不含敏感資料的公開回饋。
